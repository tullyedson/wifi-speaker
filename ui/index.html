Connect your app

Every spoken request carries a unique request ID and the speaker’s permanent ID, name, and tags.

  1. The hub POSTs a prompt to your destination URL.
  2. Your app returns 202 Accepted and works on the reply.
  3. Your app POSTs the text below to the callback URL with the app bearer token.
  4. The hub speaks it on the matching speaker. Repeating the same callback is safe for 10 minutes.
For an immediate reply, return {"text":"Your answer"} directly from the prompt endpoint.

      
Speak to a room or a group
POST to /v1/speak with the app bearer token. Select IDs, tags, or both. Every selected speaker must be online and available.
GET /v1/speakers returns names, tags, connection status, and microphone levels. Reuse a request ID only when retrying the same text and targets.
The project’s docs/API.md covers payloads, authentication, WebSocket messages, limits, and error handling.
